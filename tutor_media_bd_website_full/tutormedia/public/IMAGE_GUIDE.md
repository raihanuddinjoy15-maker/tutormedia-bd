# Image guide

Use images only where they improve trust or understanding.

1. Homepage hero: use a licensed/generated education image. Do not imply it depicts real users.
2. Tutor profiles: use real user-uploaded photos after consent; use neutral placeholders until uploaded.
3. Subject cards: optional simple icons/illustrations.
4. Tuition listings: generally no image needed.
5. Verification: use icons/badges, not fake certificates.
6. Testimonials: use only real testimonials with permission.
7. Admin pages: images are usually unnecessary.

For production, use Next/Image, lazy loading, responsive sizes, compressed WebP/AVIF, and descriptive alt text.
